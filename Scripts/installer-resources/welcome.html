Install Nyathing

👻 Nyathing displays playful animations in the macOS menu bar while commands run.

This installer installs Nyathing.app in /Applications and creates a symlink at /usr/local/bin/nyathing so you can launch Nyathing from Terminal.

⚠️ You’ll be asked to enter your administrator password during installation to authorize these changes.

Project page: https://github.com/dokwork/nyathing
