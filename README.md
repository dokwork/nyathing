# Nyathing

A native macOS menu bar animation player, built with Swift and AppKit.

## Step 1: Manual check

This first milestone displays a menu bar icon without a menu or Dock icon.

1. From the repository root, build the app:

   ```sh
   swift build
   ```

2. Launch it in the foreground:

   ```sh
   swift run nyathing
   ```

3. Confirm the star icon appears in the menu bar and Nyathing does not appear in
   the Dock.
4. Press Control-C in the terminal to stop the process. Confirm the menu bar
   icon disappears.
